# Pig Latin Translator

A simple Python program that translates English words and sentences into **Pig Latin**.

## What is Pig Latin?

Pig Latin is a word game that transforms English words using simple rules:

* If a word starts with a vowel, add `way` to the end.
  Example: `apple` → `appleway`
* If a word starts with a consonant, move the first letter to the end and add `ay`.
  Example: `hello` → `ellohay`

## Features

* Translate single words
* Translate complete sentences
* Interactive mode for continuous translation
* Exit using one of the following commands:

  * `exit`
  * `quit`
  * `bye`
  * `esc`

## Requirements

* Python +3.7

## How to Run

```bash
python main.py
```
